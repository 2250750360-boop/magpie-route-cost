# Changelog

## 1.0.0 — 2026-11-09

First public release.

- One row per underlying model across provider aliases.
- Agent × Provider detail with requests, cost, tokens, success, speed and first-token time.
- Provider speed/reliability view and paginated request log.
- Magpie gateway + CC Switch history, deduplicated by default.
- Agent / Provider / Model filters with vendor icons; minimum-token threshold.
- USD / CNY switch; unpriced models are not shown as free.
- Server binds to localhost, read-only data access.
